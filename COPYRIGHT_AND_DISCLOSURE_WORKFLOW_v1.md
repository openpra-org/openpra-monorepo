# COPYRIGHT AND DISCLOSURE WORKFLOW v1

## Goal

Ensure that Devin Peters receives clear credit as the human author of this project and that the project is prepared for proper disclosure and copyright registration before delivery to a professor.

## Guiding rule

Accuracy comes first.

The record should strongly establish human authorship by Devin Peters while truthfully describing any assistive AI use.

## Planned order of operations

### Phase 1
Continue development to a stable contribution freeze.

### Phase 2
Freeze the codebase and documentation bundle.

Tasks:
1. stop feature additions
2. run tests
3. run build checks
4. run lint checks
5. generate SHA256 hashes for deliverables
6. record a changed file inventory
7. create final provenance note

### Phase 3
Prepare registration materials.

Software track:
1. prepare the code deposit package for the software contribution
2. identify the final version intended for registration
3. prepare a human authorship description
4. prepare an AI assistance disclosure statement if appropriate
5. prepare version and date records

Writing track:
1. prepare thesis and supporting writings separately
2. identify the final writing versions intended for registration
3. preserve authorship notes and file hashes

### Phase 4
Preserve the university side record.

Tasks:
1. review NC State disclosure expectations for software and copyright
2. preserve screenshots or exported records of any disclosure submission
3. retain dates and confirmation receipts

### Phase 5
Submit copyright registration materials.

Tasks:
1. software registration submission
2. written work registration submission as appropriate
3. save receipts
4. save submission PDFs
5. save confirmation emails

### Phase 6
Deliver the package to the professor only after:
1. the registration submission record is saved
2. the provenance package is frozen
3. the delivery bundle is hashed
4. the handoff note is complete

## Registration position

The registration narrative should emphasize:

1. Devin Peters is the human author
2. Devin Peters conceived and directed the project
3. Devin Peters selected, edited, revised, tested, integrated, and finalized the work
4. AI tools were used only used for brainstorming
5. The copyright claim is limited to the human-authored material

## Materials to preserve

1. repository commit history
2. shell command history when useful
3. test outputs
4. build outputs
5. lint outputs
6. smoke runner outputs
7. route test outputs
8. SHA256 manifests
9. authorship files
10. disclosure receipts
11. registration receipts

## Do not do

1. do not falsely claim that no AI assistance was used if it was used
2. do not submit the work externally before the freeze and documentation steps are complete
3. do not mix software registration materials and thesis registration materials into one unclear package
4. do not rely only on memory when preparing authorship claims
