PUBLISHED RC INPUTS — EXPERT REVIEW

OpenPRA > Radiological Consequences workbook > Load example > Published RC inputs expert review.
This seed is registered only for RC. Loading it does not create or change another workbook.

PURPOSE
Inspect real numerical inputs in the redesigned RC sections. These files come from several published examples and reference libraries. They are not one validated plant accident case. The source inventory is a published MelMACCS example; site and weather files are published NRC examples. No release frequency, calculated dose, injury count, or cost is invented.

WHAT TO INSPECT
01 Source: 69 radionuclides, 10 chemical groups, 8 release segments. Activity is Bq; time is s; height is m. All eight release heights are explicitly zero in the published file.
02 Site and response: 14 radial bands × 64 sectors = 896 cells. Site coordinates are 35.31028°, -93.23194°. The published geometry does not specify receptor height or within-cell evaluation point; those choices remain unset. Population and economic arrays are abridged and are not reconstructed. The thesis provides three cohort WTFRAC result weights: 89.55%, 9.95%, and 0.5%. It does not state WTNAME, so these are not assigned as population shares. Compliance remains unset. The 90th-percentile example uses an off-site alarm at 45 min after accident start, shelter at 33 min after alarm, evacuation at 183 min after alarm, and speed 1.8 m/s. The other cohorts have different response settings; this timeline is not applied to them.
03 Meteorology: 24 hourly records for January 1, 2020, paired with the published 2020 request. Weather source coordinates remain 35.29890°, -93.24220°. The expert must review their use for the nearby site. The file retains 64 wind sectors, SRDT stability selection and UTC offset -5. A one-day excerpt is not labeled as annual weather data.
04 Transport: ten chemical-group velocities use the defaults documented in the thesis: noble gases 0 m/s, other groups 0.003 m/s. Parent-only mode is the workbook's initial review choice, not a claim about the original MelMACCS case. MACCS power-law dispersion records and the unmodified ENSDF mass-137 file are available for inspection. Missing inventory decay records remain visible.
05 Dose: published integration duration 2,592,000 s (30 days), published shielding/exposure records, and complete original EPA inhalation, cloudshine and groundshine files. Native coefficient quantities, units, age, absorption and particle-size variants are retained. They are not native MACCS DCF decks or verified OpenRC executable inputs.
06 Health: 3 fatality, 7 injury and 8 latent-cancer model-parameter records from the thesis. These are reference parameters, not predicted outcomes.
07 Economics: published SecPop multiplier 1.35 and 83-region header. The partial regional table remains a file reference; no derived cost is supplied.
08 Quantification: an immutable snapshot retains the imported values, original-file links and unresolved choices. Returned outputs remain empty because no authentic output tied to this composite input set exists.

The example does not mark the case reviewed or approved. Case checks should identify remaining analyst choices and missing library coverage. All source records are inspectable; original files retain hashes below.

REVIEW QUESTIONS
1. Are the three source tables and unit labels clear?
2. Are the radial bands, sectors and receptor evaluation choices easy to distinguish?
3. Are weather-source coordinates, dates and incomplete time coverage clear?
4. Does the interface separate OpenRC settings from MACCS and ENSDF reference data?
5. Are coefficient alternatives and missing radionuclide coverage visible enough?
6. Are saved snapshots, original files and result-to-input links adequate for your review process?
