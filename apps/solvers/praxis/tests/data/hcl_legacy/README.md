# Legacy HCL verification fixtures

This directory retains only model data needed to verify PRAXIS HCL numerical
semantics. It does not contain legacy GUI, plotting, profiling, benchmark, or
test-runner code.

## `lazy_k5`

Source:

```text
/Users/akrambatikh/Documents/projects/old_BDD_Engine/BDD_Engine/
  profiling/cases/old_cases/lazy_k5/
```

The case was selected because it is compact and contains all four artifacts
needed for a cross-language check:

- `FT.xml`: OpenPSA fault tree with 5 BN-bound and 12 independent events.
- `BN.xdsl`: original six-node binary BN.
- `mapping.yaml`: the original event-to-node mapping; `I0` through `I4` map to
  the corresponding BN node and use state `True`.
- `BN_unified.xdsl`: unified network generated by the old Python HCL tooling.

The `<nodes>` sections and all numerical values are retained. GeNIe
`<extensions>` blocks were removed from both XDSL files because they contain
only presentation metadata. No probabilities, states, parent order, fault-tree
logic, or mappings were changed.

The Rust test intentionally encodes the five simple mappings instead of adding
a YAML dependency solely for this frozen fixture.

See [`../../../docs/HCL_VERIFICATION.md`](../../../docs/HCL_VERIFICATION.md) for
the verification method and recorded result.
